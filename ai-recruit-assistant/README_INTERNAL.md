# AI 招聘助手部门内部安装说明

适用对象：部门 HR / 招聘同学 / 内部试用人员。

## 1. 安装 Python

1. 打开 <https://www.python.org/downloads/>。
2. 安装 Python 3.10 或以上版本。
3. 安装时务必勾选 `Add python.exe to PATH`。
4. 打开命令行验证：

```bat
python --version
```

能看到 Python 版本号即安装成功。

## 2. 安装本地服务依赖

解压内部试用包后，双击：

```text
install.bat
```

该脚本会进入 `local_server` 并执行：

```bat
python -m pip install -r requirements.txt
```

看到 `Install complete` 即依赖安装完成。

## 3. 启动本地服务

双击：

```text
start.bat
```

启动命令等价于：

```bat
cd local_server
python -m uvicorn main:app --reload --port 8787
```

启动后不要关闭窗口。浏览器访问：

```text
http://127.0.0.1:8787/health
```

看到：

```json
{"status":"ok"}
```

说明本地服务已连接。

## 4. 加载 Edge 插件

1. 打开 Edge。
2. 地址栏输入：

```text
edge://extensions/
```

3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择解压目录中的：

```text
plugin
```

注意：选择的是 `plugin` 文件夹，不是 zip 文件。

## 5. 保存岗位要求库

BOSS 聊天页通常只能抓到岗位名称，抓不到完整 JD。第一次遇到岗位时：

1. 打开 BOSS 聊天页并点击具体候选人会话。
2. 打开插件，点击“刷新上下文”。
3. 在“当前岗位”区域填写：
   - 岗位描述
   - 岗位职责
   - 任职要求
   - 关键词
4. 点击“保存岗位要求库”。

下次遇到同名岗位，插件会自动加载已保存的 JD。

## 6. 打开 BOSS 页面使用

1. 确认 `start.bat` 服务窗口正在运行。
2. 打开：

```text
https://www.zhipin.com/web/chat/index
```

3. 点击具体候选人会话。
4. 打开插件并点击“刷新上下文”。
5. 如岗位缺少 JD，先保存岗位要求库。
6. 点击“分析候选人”。
7. 点击“生成话术”。
8. 可复制或填入输入框，但必须人工检查后再发送。

> 当前版本不会自动发送消息，也不会批量自动打招呼。

## 7. 常见问题

### 本地服务未连接

- 确认 `start.bat` 窗口没有关闭。
- 访问 `http://127.0.0.1:8787/health` 检查是否返回 `{"status":"ok"}`。
- 如果端口被占用，关闭旧的 Python/uvicorn 窗口后重试。

### 插件无法读取页面

- 确认加载的是 `plugin` 文件夹。
- 刷新 BOSS 页面。
- 点击具体候选人会话后再点“刷新上下文”。

### 岗位缺少 JD

- 这是 BOSS 聊天页的正常限制。
- 请在“当前岗位”区域补充岗位描述、岗位职责、任职要求和关键词。
- 点击“保存岗位要求库”后再分析。

### 话术不准确怎么办

- 先确认岗位要求库是否完整。
- 再确认候选人页面是否打开了在线简历或右侧信息足够完整。
- 重新点击“刷新上下文”和“分析候选人”。
- 话术仅作参考，发送前必须人工检查。
