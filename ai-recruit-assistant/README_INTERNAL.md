# AI 招聘助手：部门内部试用版使用说明

适用对象：部门 HR、招聘同学、内部试用人员。本文按“零技术基础”编写。

## 1. 这个工具是什么

AI 招聘助手是一个本地运行的小工具，由两部分组成：

1. **Edge 浏览器插件**：在 BOSS 页面读取候选人、岗位、聊天上下文，辅助分析和生成参考话术。
2. **本地服务**：运行在自己电脑上，地址是 `http://127.0.0.1:8787`，用于保存候选人、岗位、匹配记录和 dashboard 数据。

> 内部试用版不会自动发送消息。所有话术都必须由 HR 人工检查后再发送。

## 2. 使用前准备

请确认电脑上安装了：

- Windows 10/11
- Microsoft Edge 浏览器
- Python 3.10 或以上版本

安装 Python 时务必勾选：

```text
Add python.exe to PATH
```

如果不确定环境是否正常，可以先双击：

```text
check_env.bat
```

## 3. 第一次安装步骤

### 第一步：双击 `install.bat`

在解压后的工具目录中，双击：

```text
install.bat
```

它会自动：

1. 检查 Python 是否可用。
2. 进入 `local_server`。
3. 升级 pip。
4. 安装本地服务依赖。

看到以下提示即安装完成：

```text
安装完成，请双击 start.bat 启动服务。
```

## 4. 每天启动步骤

每天开始使用前，双击：

```text
start.bat
```

启动后会出现一个黑色窗口，标题为：

```text
AI Recruit Assistant Local Server
```

请注意：

- 使用过程中不要关闭这个窗口。
- 如果关闭窗口，插件会显示本地服务未连接。

验证服务是否启动成功：

```text
http://127.0.0.1:8787/health
```

看到：

```json
{"status":"ok"}
```

说明服务正常。

## 5. Edge 插件加载步骤

### 第一步：打开 Edge 扩展页面

在 Edge 地址栏输入：

```text
edge://extensions
```

### 第二步：打开开发人员模式

页面左侧或右上角找到“开发人员模式”，打开开关。

### 第三步：加载插件文件夹

点击：

```text
加载解压缩的扩展
```

选择当前工具目录中的：

```text
plugin
```

注意：请选择 `plugin` 文件夹，不要选择 zip，也不要选择整个项目文件夹。

## 6. BOSS 页面使用流程

1. 先双击 `start.bat`，保持本地服务运行。
2. 打开 BOSS 聊天页面。
3. 点击一个具体候选人会话。
4. 打开 AI 招聘助手插件。
5. 点击“刷新上下文”。
6. 检查候选人、岗位信息是否显示。
7. 点击“分析候选人”。
8. 点击“生成话术”。
9. 人工检查话术后，再决定是否复制或填入。

## 7. 如何保存岗位

岗位信息完整时：

1. 打开插件。
2. 点击“刷新岗位”或“刷新上下文”。
3. 确认岗位名称、城市、薪资、职责、要求已经显示。
4. 点击：

```text
保存岗位
```

如果想保存完整 JD 到岗位要求库，点击：

```text
保存岗位要求库
```

建议先在 BOSS 岗位详情页打开完整 JD，再保存岗位要求库。

## 8. 如何保存候选人

1. 打开 BOSS 候选人聊天或在线简历。
2. 点击插件里的“刷新上下文”。
3. 确认候选人姓名、职位、技能或简历内容已显示。
4. 点击：

```text
保存候选人
```

保存成功后，会提示：

```text
候选人已保存，联系方式/项目/公司/风格信息已同步
```

## 9. 如何查看 dashboard

打开浏览器访问：

```text
http://127.0.0.1:8787/dashboard
```

这里可以查看：

- 今日数据概览
- 候选人列表
- 岗位列表
- 匹配记录列表
- 候选人联系方式
- 公司、项目、风格、关键词资产

## 10. 如何搜索候选人

在 dashboard 顶部搜索框输入关键词，例如：

```text
网易
SLG
二次元
微信
```

点击“搜索”，即可查找对应候选人。

也可以直接访问接口：

```text
http://127.0.0.1:8787/api/candidates/search?q=网易
```

## 11. 常见问题

### 插件显示“本地服务未连接”

处理：

1. 检查 `start.bat` 窗口是否还开着。
2. 打开 `http://127.0.0.1:8787/health`。
3. 如果打不开，重新双击 `start.bat`。

### `/health` 打不开

处理：

1. 运行 `check_env.bat`。
2. 确认 Python 已安装。
3. 确认已运行过 `install.bat`。
4. 关闭重复的服务窗口后重新启动。

### 插件抓不到 BOSS 页面

处理：

1. 刷新 BOSS 页面。
2. 重新加载 Edge 插件。
3. 确认不是在 `edge://` 页面测试。
4. 先点击具体候选人会话，再点“刷新上下文”。

### 保存候选人后 dashboard 没看到

处理：

1. 点击 dashboard 的“刷新数据”。
2. 打开 `http://127.0.0.1:8787/api/candidates` 查看是否有数据。
3. 查看 `start.bat` 窗口是否有报错。

### 数据库在哪里

数据库文件在：

```text
local_server/data/recruitment.db
```

### 如何清空测试数据

1. 关闭 `start.bat` 服务窗口。
2. 删除：

```text
local_server/data/recruitment.db
```

3. 重新双击 `start.bat`，系统会自动生成新的空数据库。

## 12. 建议的日常使用顺序

每天：

1. 双击 `start.bat`。
2. 打开 Edge 和 BOSS。
3. 确认插件已加载。
4. 进入候选人会话。
5. 刷新上下文。
6. 保存岗位 / 保存候选人。
7. 分析候选人。
8. 打开 dashboard 查看沉淀数据。
