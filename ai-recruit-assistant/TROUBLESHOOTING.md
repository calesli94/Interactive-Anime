# AI 招聘助手内部试用版故障排查

## 1. 插件显示“本地服务未连接”

处理步骤：

1. 检查 `start.bat` 黑色窗口是否还在运行。
2. 打开浏览器访问：

```text
http://127.0.0.1:8787/health
```

3. 如果返回：

```json
{"status":"ok"}
```

说明服务正常，刷新 BOSS 页面后再打开插件。

## 2. `/health` 打不开

处理步骤：

1. 重新双击 `start.bat`。
2. 如果窗口一闪而过，先双击 `check_env.bat` 检查环境。
3. 确认电脑已安装 Python 3.10+。
4. 确认首次使用前已双击运行 `install.bat`。

## 3. 插件抓不到页面

处理步骤：

1. 刷新 BOSS 页面。
2. 重新打开 Edge 插件页面 `edge://extensions`，点击本插件的“重新加载”。
3. 确认当前测试页面不是 `edge://`、`chrome://` 或插件管理页。
4. 在 BOSS 聊天页中先点击具体候选人会话，再点插件里的“刷新上下文”。

## 4. 保存候选人没有数据

处理步骤：

1. 点击插件里的“刷新上下文”。
2. 确认候选人姓名、职位、技能或简历文本已经显示。
3. 点击“保存候选人”。
4. 打开：

```text
http://127.0.0.1:8787/api/candidates
```

5. 如果仍为空，查看 `start.bat` 窗口后端日志，把错误信息发给技术同学。

## 5. 岗位信息丢失

处理步骤：

1. 在岗位详情页或岗位信息完整时，先点击“保存岗位要求库”或“保存岗位”。
2. 再切换候选人聊天页面。
3. 打开 dashboard 或岗位库确认岗位已保存。
4. 如仍丢失，刷新上下文并重新加载岗位要求库。

## 6. 数据库在哪里

数据库文件位置：

```text
local_server/data/recruitment.db
```

这是本机本地数据库，不会自动上传到外部服务。

## 7. 如何清空测试数据

1. 先关闭 `start.bat` 服务窗口。
2. 删除文件：

```text
local_server/data/recruitment.db
```

3. 重新双击 `start.bat`。
4. 系统会自动生成新的空数据库。

## 8. 8787 端口被占用

处理步骤：

1. 关闭重复打开的 `start.bat` 窗口。
2. 再次运行 `check_env.bat`。
3. 如果仍提示端口占用，重启电脑后再双击 `start.bat`。
