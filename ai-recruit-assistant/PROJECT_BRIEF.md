# 项目简介（PROJECT BRIEF）

## 项目名称
AI招聘助手本地安装版

## 背景与目标
本项目用于构建一个“浏览器插件 + 本地服务”的招聘效率工具。核心目标是：
1. 在候选人浏览场景中提供快捷操作入口；
2. 通过本地 FastAPI 服务管理候选人、消息、队列与统计；
3. 使用 SQLite 做本地数据持久化，满足轻量化部署；
4. 支持后续扩展桌面端与打包安装流程。

## 第一阶段交付范围
- 基础目录结构搭建；
- Chrome 插件入口文件（manifest、popup、content、样式）；
- FastAPI 本地服务入口与服务模块骨架；
- 安装打包脚本占位。

## 技术选型
- 插件端：Chrome Extension (Manifest V3)
- 服务端：FastAPI + Uvicorn
- 数据库：SQLite
- 语言：Python / JavaScript / HTML / CSS

## 后续扩展方向
- 候选人优先级自动评估与排序；
- 模式切换（自动/半自动/手动）；
- 聊天记录沉淀与检索；
- 统计看板与招聘漏斗分析。
